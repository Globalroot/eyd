title: Gabungan Huruf Konsonan
---

Gabungan huruf konsonan _kh_, _ng_, _ny_, dan _sy_ melambangkan satu bunyi konsonan.

| Gabungan Huruf Konsonan | Bunyi Fonem |Posisi Awal | Posisi Tengah | Posisi Akhir |
| ----------------------- | ----------- | ---------- | ------------- | ------------ |
| kh                      |x            |*kh*usus    | a*kh*ir       | tari*kh*     |
| ng                      |ŋ            |*ng*arai    | ba*ng*un      | sena*ng*     |
| ny                      |ɲ            |*ny*ata     | ba*ny*ak      | -            |
| sy                      |ʃ            |*sy*arat    | mu*sy*awarah  | ara*sy*      |
